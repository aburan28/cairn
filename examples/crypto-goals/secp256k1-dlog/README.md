# Full-order secp256k1 discrete-log challenge

This objective asks for one scalar in the full prime-order subgroup generated
by the standardized secp256k1 base point. The field, curve, generator, and
subgroup order come from [SEC 2, version 2.0, section 2.7.1][sec2].

The target is not generated by picking a scalar and discarding it. The pinned
checker derives `Q` from the fixed public seed
`cairn/crypto-goals/secp256k1/full-dlog/v1`: it hashes successive 32-bit
counters with SHA-256, maps each digest to an x-coordinate modulo `p`, and
selects the first x for which `x^3 + 7` has a square root. Since `Q` is not
constructed as `[k]G`, the instance creator has no known answer to withhold.
Everyone derives the same target from the checker source.

Artifacts contain exactly one field:

```json
{"k": "64 lowercase hexadecimal digits"}
```

The checker verifies canonical encoding, the scalar range, the curve equation,
subgroup membership, and `[k]G = Q` using exact integer arithmetic. It does
not trust a score or a submitter's claim about the search method. The
self-test uses a small curve fixture for a positive certificate, rejects
malformed inputs, and re-derives and checks the secp256k1 target and subgroup
membership.

The expected generic discrete-log work is on the order of `2^128` group
operations, up to method-specific constant factors. This makes the objective a
long-horizon benchmark; it is not expected to settle soon. Cairn's Stage 0
reward is notional and is not an external prize.

## Reproduce validation

```sh
python3 examples/crypto-goals/secp256k1-dlog/selftest.py
sha256sum examples/crypto-goals/secp256k1-dlog/checkers/secp256k1_dlog.py
```

[sec2]: https://www.secg.org/sec2-v2.pdf
