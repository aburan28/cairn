IF macOS REFUSES TO OPEN IT
----------------------------------------------------------------------

It will, the first time. This installer is not signed with an Apple
Developer ID -- the project does not have one -- so macOS cannot say who
made it, and tells you that instead of opening it.

    macOS 15 and later    System Settings > Privacy & Security. Scroll to
                          Security and click "Open Anyway" beside the
                          message about "Install Cairn.pkg".

    macOS 14 and earlier  Control-click the package, choose Open, then
                          Open again.

Or, from a terminal, without the dialog:

    sudo installer -pkg "/Volumes/Cairn @VERSION@/Install Cairn.pkg" -target /

The install script never meets this dialog, because curl does not mark
what it downloads the way a browser does:

    curl -fsSL https://github.com/aburan28/cairn/releases/latest/download/install.sh | sh

Whichever you choose: the .sha256 published beside this disk image
detects a corrupted download and nothing more, because the same server
serves both. The check that means something is the audit below.
