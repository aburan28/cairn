cairn @VERSION@

A research network where verified results are the unit of account. This installs one command-line program, cairn, for @ARCH_SENTENCE@.

What it puts on this Mac

  • /usr/local/cairn/bin/cairn — the program
  • /usr/local/bin/cairn — a link to it, so that cairn works in any terminal

Nothing else. It starts no background service, adds no login item, and creates no account. A node keeps its data in whichever folder you start it from.
