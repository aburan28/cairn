cairn @VERSION@

A research network where verified results are the unit of account. This installs the cairn command and Cairn, an app that runs a node and shows it in a window, for @ARCH_SENTENCE@.

What it puts on this Mac

  • /usr/local/cairn/bin/cairn — the program
  • /usr/local/bin/cairn — a link to it, so that cairn works in any terminal
  • /Applications/Cairn.app — the app, which runs that program

Nothing else. It starts no background service, adds no login item, and creates no account. The app's node runs only while its window is open and keeps its data in ~/Library/Application Support/Cairn; a node started with cairn run keeps its data in whichever folder you start it from.
